🚀

One-Command Deploy

Stage, commit, pull rebase, dan push dalam satu baris perintah.

💾

Backup Semua Repo

Cadangkan seluruh repositori GitHub kamu ke folder lokal secara paralel.

⏪

Undo Apapun

Batalkan commit, pulihkan file, atau reset total dengan konfirmasi aman.

🔄

Daemon Auto-Sync

Sinkronisasi otomatis setiap N detik dengan PID lockfile agar tidak dobel.

🔒

Input Validation

Karakter berbahaya diblokir di semua command. Commit message tetap fleksibel.

🌐

Bilingual (EN/ID)

Dukung Bahasa Indonesia dan Inggris. Ganti dengan export GITFLUX_LANG=id.

📋 Changelog

  • REBRAND Gitzen → Gitflux. Nama baru, semangat baru. Semua referensi, env var (GITFLUX_LANG), lockfile (/tmp/gitflux.lock), SSH key (id_ed25519_gitflux), dan default backup folder (~/gitflux-backups) sudah diperbarui.
  • FIX String hardcoded "Commit dibatalkan" dan "tidak disetel" di cmd_sync & cmd_status diganti ke sistem bilingual T_*.
  • IMPROVED validate_arg() sekarang mengizinkan karakter $ khusus untuk commit message, agar pesan seperti "fix: update $PATH" tidak diblokir.
  • NEW Fungsi validate_arg() terpusat diterapkan di seluruh command — branch, tag, remote, PR, issue, config, dan lainnya.
  • FIX cmd_init kini menggunakan git -C — tidak ada lagi masalah cd dalam subshell.
  • FIX fail() sekarang output ke stderr (>&2) agar error tidak tercampur dengan stdout.
  • IMPROVED Daemon menggunakan PID-based lockfile — mencegah instance ganda bahkan setelah crash.

⚡ Quick Install

curl -sL https://raw.githubusercontent.com/Ziferd/Gitflux/main/Gitflux.sh -o $PREFIX/bin/gitflux && chmod +x $PREFIX/bin/gitflux && gitflux setup

Lalu ketik gitflux help untuk melihat semua perintah.
